tsc-diagnostics — UI Component Library

One self-contained HTML file per UI component used across aggregate-template.html, report-template.html, and compare-template.html — each with inline styles/scripts and hardcoded demo data, matching the inventory in ../../UI-COMPONENTS.md. Entries under container/ assemble several of these components together (e.g. cards + table + badges) rather than rendering a single one.
